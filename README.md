# 🌍 Carbon Accounting Platform – Frontend Prototype

## 📌 Overview

This project is a frontend prototype of a Carbon Accounting and ESG Reporting platform developed as part of a hackathon concept.

The goal of this platform is to provide an intuitive interface for tracking energy consumption, managing carbon emissions, and visualizing sustainability-related data.

---

## 🚀 Features

- User Login Interface  
- Buyer & Field User Dashboard  
- Marketplace UI for Carbon Credits  
- Structured ESG Reporting Pages  
- Clean and Modular Frontend Architecture  

---

## 🛠 Tech Stack

- HTML5  
- CSS3  
- JavaScript  

---

## 📂 Project Structure

```
public/      → HTML pages  
src/css/     → Styling files  
src/js/      → JavaScript logic  
src/images/  → Assets  
```

---

## 🎯 Purpose

This is a frontend prototype version created to validate user flow and UI structure.

Backend integration, database connectivity, and blockchain-based verification are planned for future development.

---

## 🔮 Future Improvements

- Backend integration (Node.js)  
- Database connectivity  
- Carbon emission calculation engine

- Dashboard analytics
